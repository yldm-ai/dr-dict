      释义的“繁”按钮

      每部词典标题右侧的“原 / 简 / 繁”切换释义的写法。点“繁”时默认转成这里选的繁体，也可以用它旁边的箭头给某部词典单独选择。

      查词操作

      按住 Ctrl，快速按两次 C。DR Dict 需保持运行（可最小化）。

      双击词条正文中的词继续查询；Ctrl K 聚焦搜索框；Alt ← / Alt → 后退与前进。

      小牛翻译

      译文显示在词条上方，可一键复制。要翻译的文字会发送到小牛翻译的服务器（api.niutrans.com）。

      在 niutrans.com 注册后进入“控制台 → API 应用”，开通文本翻译即可得到 App ID 和 API Key（）。密钥用 Windows 数据保护加密后保存在本机。

      维基词典

      查单词时，维基词典的释义显示在本地词典之后，只保留英语、汉语等相关语言的部分。查询的词会发送到 wiktionary.org；内容按 CC BY-SA 4.0 协议授权。

      查询历史

      最近查过的词只保存在本机。

      索引

      词典变化后，可在“词典库”中为单部词典重建索引。
